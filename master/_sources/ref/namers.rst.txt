=======
Namers
=======

easy-thumbnails allows you to customize how thumbnail filenames are
generated by setting
:attr:`~easy_thumbnails.conf.Settings.THUMBNAIL_NAMER` to the dotted path
of a namer function.

================

.. automodule:: easy_thumbnails.namers
   :members:


Custom namers
==============

To write a custom namer, always catch all other keyword arguments (with
``**kwargs``). You have access to the following arguments:
``thumbnailer``, ``source_filename``, ``thumbnail_extension`` (does *not*
include the ``'.'``), ``thumbnail_options``, ``prepared_options``. The namer
must return a filename.

The ``thumbnail_options`` are a copy of the options dictionary used to build
the thumbnail, ``prepared_options`` is a list of options prepared as text, and
excluding options that shouldn't be included in the filename:

.. automethod:: easy_thumbnails.options.ThumbnailOptions.prepared_options
