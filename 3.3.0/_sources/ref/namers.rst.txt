=======
Namers
=======

easy-thumbnails allows you to customize how thumbnail filenames are
generated by setting
:attr:`~easy_thumbnails.conf.Settings.THUMBNAIL_NAMER` to the dotted path
of a namer function.

Custom namers receive ``thumbnailer``, ``source_filename``,
``thumbnail_extension``, ``thumbnail_options``, and ``prepared_options``
keyword arguments and must return a filename.
